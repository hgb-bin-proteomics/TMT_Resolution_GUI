# TMT Resolution GUI

Extracts TMT reporter ion intensity, noise, and resolution from the corresponding mass spectra.

This tool is based on the Resolution GUI tool developed by Dina L. Bai, Tian Zhang _et al._
[\[1\]](https://doi.org/10.1038/s41467-025-60022-x) and was
slightly modified to support European localization and mass spectra recorded in DIA acquisition.

## Usage

- The tool requires [.NET Framework 4.7.2](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net472)
  but should also run on any current [.NET](https://dotnet.microsoft.com/en-us/download) version.
- Download the `Application` folder.
- Run `GetMS2Resolution_GUI.exe`!
